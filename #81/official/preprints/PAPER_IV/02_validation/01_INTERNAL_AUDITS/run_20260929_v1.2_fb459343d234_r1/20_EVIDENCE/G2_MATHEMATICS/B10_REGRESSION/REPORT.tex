\subsection{Reproducción y evidencia}\label{reproducciuxf3n-y-evidencia}

Ejecutar con Python 3.12 \nolinkurl{scripts/cycle_chordality.py}. Los
JSON, stdout y stderr de \nolinkurl{results/} son la evidencia de
ejecución. El runner guarda comandos, duración, límite y código de
salida. Las ampliaciones exactas usan \nolinkurl{extension_checks.py}; no
invocan Lean.

Un solo proceso propio a la vez; las regresiones serializadas tienen
límite de 2 GiB y 120 segundos, Certo 60 segundos por instancia. Se usan
versiones registradas en \nolinkurl{ENVIRONMENT.json}, sin instalar
dependencias.
