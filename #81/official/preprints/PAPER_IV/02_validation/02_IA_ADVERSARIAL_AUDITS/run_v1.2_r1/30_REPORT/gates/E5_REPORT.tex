\subsection{Method conventions}\label{method-conventions}

\begin{itemize}
\item
  A verdict is decided only in exact arithmetic: Python \texttt{int} and
  \texttt{Fraction}, sympy polynomial identities, or z3 decision
  procedures for linear and nonlinear real arithmetic.
\item
  \textbf{LP values W*.} HiGHS proposes a solution. It is then rebuilt
  as exact rationals in one of two ways: \texttt{limit\_denominator},
  or, as a fallback, an exact Gaussian solve of the optimal simplex
  basis returned by HiGHS. Primal feasibility, dual feasibility and
  equal objective are all verified exactly. An instance without such a
  certificate would be INCONCLUSIVE. In the final runs, every LP (1253
  in T15, 36 in T06s, 36 in T17) is exactly certified.
\item
  \textbf{ILP values (cp, c\_r).} CBC returns a partition, which is
  re-verified exactly: every piece is a clique, of order ≥2 and ≤r, and
  every edge is covered exactly once. A value is labelled exact only if
  an independent exact lower bound matches it. The bounds used are:

  \begin{itemize}
  \tightlist
  \item
    an exhaustively checked weight (dual) certificate, where every
    clique has weight ≤1 (T10, T11);
  \item
    the parity argument (T16);
  \item
    ⌈F\_4⌉ from an exact W* (INFO\_c4).
  \end{itemize}

  Otherwise the value is solver-dependent.
\item
  \textbf{rsd.} Computed by brute force over all U ⊆ V and all cliques R
  ⊊ U, taking the maximum over maximal cliques of G{[}U{]}, which is
  equivalent. Self-test: rsd = 0 ⟺ chordal on all 1253 atlas graphs,
  with zero mismatches (\texttt{networkx.is\_chordal}). Also rsd(C4) = 1
  and rsd(K\_\{3,3\}) = 2.
\end{itemize}

\subsection{Discussion of power and
non-results}\label{discussion-of-power-and-non-results}

\begin{itemize}

\item

  long cycles when rsd=0, it has almost no falsifying power.

  \textbf{Low power in the T15 band condition.} At n≤7 the refined bound

  therefore does not exercise the necessity of the band. It does
  exercise both bounds: the minimum slack is 0 for each.

  are 3 (s=1) and 10 (s=2) against 5 and 18. It also follows

  c≥20(s+1)² is out of exhaustive range. Without that hypothesis it
  fails for small c (24 cases with c≤7). This is expected and is not a
  finding.
\item
  \textbf{T04 is conditional.} It verifies the arithmetic of
  (5.12)-(5.14) \emph{given} the premises (5.12). The derivation of
  those premises from the regularisation estimates (5.4), (5.7) is a
  proof obligation; the manuscript lists it in A.2 as "not fully
  expanded". Finite computation cannot establish it.
\end{itemize}
