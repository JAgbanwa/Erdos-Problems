than the published results; whether they are used only where the paper says.

arXiv:1503.08191 (abstract states verbatim the combined result: "for all ε > 0,
every large enough triangle divisible graph on n vertices with minimum degree at
least (0.9 + ε)n admits a triangle decomposition"). Citation metadata checked
against public indices. Usage localization by mechanical census (Block A).

sources); AX2 is character-for-character the published combined statement, with
triangle-divisibility spelled out in its standard (correct) form. Usage: AX1 only
§4.3/§9.1, AX2 only §8.3, Prop 10.1 uses neither — all confirmed.
Coverage boundary: Combinatorica/Adv. Math. full texts are paywalled; verification
rests on the primary arXiv abstracts (verbatim) + secondary corroboration.
Details: `results/blockB_literature_verification.md`.
