Start with the [bilingual series explainer](../index.html). Paper IV has a
consolidated external E0–E8 PASS on its exact v1.22-r4 artifacts. The v1.23
editorial revision preserves the mathematics and Lean freeze; see its
[changelog](PAPER_IV/CHANGELOG_v1.23.md) and separate documentary checks.

Packages use 01_manuscript, 02_validation, 03_reproducibility, 04_integrity,
05_formalization and superseded. Only v1.23 is offered as the current
Paper IV manuscript. Its v0.8 public draft is [superseded](PAPER_IV/superseded/README.md).
Other manuscript versions occur solely in audit backups, including the
published v1.22 baseline. Unrelated working drafts are excluded. The released
Papers I–III packages are unchanged.

These are author preprints, not human peer-reviewed publications. The author
approved GitHub publication of v1.23 on 1 October 2026. A new Zenodo deposit
is a separate action.
